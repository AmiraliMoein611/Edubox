# EduBox | جعبه‌ابزار دانش‌آموزی

یک سایت فارسی (راست‌چین) شامل ابزارهای کاربردی برای دانش‌آموزان پایه دهم، با حساب کاربری اختصاصی و پنل مدیر. کل سایت یک فایل `index.html` است و روی هر هاست استاتیک اجرا می‌شود. داده‌ها (حساب‌ها، برنامه امتحانی، نتایج) در Supabase ذخیره می‌شوند.

## امکانات

- **ورود اجباری:** بدون حساب فقط صفحه ورود و ثبت‌نام دیده می‌شود.
- **ثبت‌نام با تأیید مدیر:** حساب جدید «در انتظار تأیید» می‌ماند تا مدیر آن را بپذیرد.
- **درصدگیر:** حالت تک‌درس و چنددرس، نمره منفی استاندارد (هر غلط یک‌سوم یک صحیح)، ضریب هر درس، تاریخچه و نمودار پیشرفت برای هر درس و درصد کل.
- **تبدیل واحد:** طول، جرم، مساحت، حجم، دما، زمان، سرعت، نیرو، فشار، انرژی، توان، حجم داده، زاویه و چند واحد قدیمی ایرانی.
- **علوم و ریاضی:** محاسبه جرم مولی و جدول سینوس، کسینوس، تانژانت و کتانژانت زاویه‌های مهم.
- **امتحان‌های پیش رو:** شمارش معکوس زنده تا نزدیک‌ترین امتحان هر کلاس و تایم‌لاین بقیه.
- **پنل مدیر:** تأیید یا رد ثبت‌نام‌ها، ثبت برنامه امتحانی هر کلاس و مشاهده آمار تجمیعی (بدون دسترسی به نتایج شخصی).

## راه‌اندازی

1. در [supabase.com](https://supabase.com) یک پروژه بسازید.
2. فایل `edubox-setup.sql` را در بخش SQL Editor پروژه اجرا کنید (جدول‌ها و تابع‌ها ساخته می‌شوند).
3. در `index.html` مقدار `SUPA` (آدرس پروژه) و `KEY` (کلید publishable) را با مقدار پروژه خودتان جایگزین کنید.
4. نام کاربری و رمز مدیر را در `index.html` (ثابت `ADMIN`) و در اسکریپت SQL (تابع `_admin_ok`) یکسان تنظیم کنید.
5. فایل `index.html` را روی هاست قرار دهید.

## فناوری

HTML، CSS و JavaScript خالص (بدون فریم‌ورک و بدون مرحله build) و Supabase (Postgres) برای ذخیره داده. فقط فونت Vazirmatn از Google Fonts بارگذاری می‌شود.

## نکته امنیتی

نام کاربری و رمز مدیر داخل کد صفحه است و هر کسی که کد را ببیند آن را می‌بیند. این پروژه برای استفاده مدرسه‌ای ساخته شده است. اگر مخزن عمومی است، قبل از انتشار رمز را عوض کنید. کلید `secret` یا `service_role` را هرگز در کد قرار ندهید.
